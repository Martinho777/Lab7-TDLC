## Ejercicio 2

Para ejecutar el programa:

```bash
cd Ejercicio2
python3 grammar_simplifier.py gramatica1.txt gramatica2.txt
```

El programa valida las líneas mediante regex, detecta símbolos anulables, genera las combinaciones `2^m` solicitadas y muestra la gramática resultante sin producciones-ε. Las instrucciones completas están en [`Ejercicio2/README.md`](./Ejercicio2/README.md).
